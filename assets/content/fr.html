📖 À propos

Pipeline complet en un clic : décompression → suppression de publicités → contournement de signature → optimisation de taille → réempaquetage → signature, le tout traité localement et hors ligne, sans réseau.

Contrairement au flux traditionnel de désassemblage/remontage smali, il utilise le patchage direct du bytecode, ce qui accélère plusieurs fois le traitement tout en restant précis.

✨ Fonctionnalités

🛡 Contournement de signature (nouveau en v3.0)

  • Injection KillerApplication type MT Manager : injecte une classe hook avec 12 classes internes en DEX indépendant, réécrit la classe parente du Application cible et remplit par réflexion PackageInfo.CREATOR avec la signature originale, couvrant la plupart des vérifications Java
  • Double mode : Normal (hooks pour la couche Java) / Original (renforcé, embarque origin.apk + lib native pour couvrir aussi la couche native)
  • Injection SO intelligente : détecte l'ABI, n'écrit que dans les répertoires existants (arm64-v8a / armeabi-v7a...) ; si pas de lib, écrit toutes les architectures (incl. x86 / x86_64)
  • Nom de classe hook personnalisable : KillerApplication renommable librement, 12 classes renommées via dexlib2 pour éviter la détection
  • Paramètres d'injection personnalisables : chemin original / extraction / nom du so / hook / signature / entrée ; valeurs réelles si laissés vides
  • Ne touche pas aux méthodes métier : contrairement à "annuler les méthodes de vérification", pas de suppositions fragiles, pas de gel de démarrage, même solidité que MT Manager
  • Protection anti-crash : sauvegarde + écriture atomique + récupération automatique

🛡 Noyau de suppression de publicités

  • 18 catégories de fonctionnalités publicitaires : libs SDK / permissions / classes / méthodes / ressources / URLs / Views / Activities / Services / Receivers, personnalisables avec reset
  • Traitement AXML profond : supprime composants, permissions et masque les Views publicitaires du layout
  • Précision niveau méthode : annule les méthodes des classes pub, vide liens et géométrie
  • Déblocage premium : force true/false pour débloquer les fonctions payantes
  • Nettoyage des ressources pub : libs natives du SDK pub (.so), ressources assets pub, fichiers racine pub
  • Support Flutter : analyse la snapshot AOT Dart, efface les signatures de chaînes pub dans libapp.so

📦 Optimisation de taille

  • Réutilisation de données : les paquets contournés (artefacts LSPatch) réutilisent la section originale, jusqu'à ~50 % de réduction
  • Détection d'APK renommé : reconnaît les APK sans extension ou à extension arbitraire
  • Optimisation DEX : supprime les infos de debug (numéros de ligne/variables locales), encore 5 %~15 %
  • Compression intelligente + alignement ZIP : garantit une installation correcte

🔒 Stabilité et sécurité

  • Double signature v1 + v2, compatible avec les vieux appareils
  • Protection anti-crash DEX : sauvegarde + écriture atomique + récupération
  • Protection path traversal : corrige Zip Slip, bloque les écritures hors limites
  • Scan basse mémoire : gère les gros DEX sans gel

🚀 Démarrage rapide

Compiler

# Prérequis : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Artefacts dans app/build/outputs/apk/release/, installables directement.

Ce projet a une compilation auto GitHub Actions : chaque push/PR compile Debug et Release ; publier une étiquette v* publie une Release avec les APK.

Notes de version par release-drafter : étiquète les PR par titre/branche/fichiers et agrège un changelog structuré.

Utilisation

  1. Sélectionnez l'APK (APK renommés supportés)
  2. Appuyez sur "Démarrer" : décompression, suppression, optimisation, réempaquetage, signature
  3. Export vers le répertoire original + rapport Markdown

🏗 Architecture

Module Techno Description
Moteur de patch DEX dexlib2 2.5.2 modification directe du bytecode
Contournement Injection KillerApplication hook type MT + réécriture Application + réflexion
Processeur AXML parser maison analyse les chunks, supprime composants/permissions
Réutilisation ApkDataMultiplexing réutilise la section originale
Signature apksig + V2V3SchemeSigner double v1/v2, signature dédiée
Flutter Snapshot AOT Dart efface les chaînes dans libapp.so
Empaquetage moteur ZIP maison compression + alignement + protection
