📖 Informazioni

Pipeline completa in un clic: estrazione → rimozione pubblicità → bypass della firma → ottimizzazione delle dimensioni → ri-pacchettizzazione → firma, tutto elaborato in locale e offline, senza bisogno di una connessione di rete.

A differenza del tradizionale flusso smali disassembla-riassembla, utilizza il patching diretto del bytecode, che aumenta di diverse volte la velocità di elaborazione mantenendo la precisione.

✨ Funzionalità

🛡 Bypass della firma (novità in v3.0)

  • Iniezione KillerApplication stile MT Manager: inietta una classe hook con 12 classi interne come DEX autonomo, riscrive la classe padre dell'Application di destinazione e in fase di esecuzione riempie per riflessione PackageInfo.CREATOR con la firma originale, coprendo la maggior parte dei controlli di firma a livello Java
  • Bypass a doppia modalità: Normale (inietta hook per coprire i controlli Java) / Originale (incorpora in più origin.apk + libreria nativa per coprire i controlli di firma della rilettura su disco a livello nativo)
  • Iniezione SO intelligente: rileva automaticamente l'ABI dell'APK di destinazione, scrivendo solo nelle directory esistenti (arm64-v8a / armeabi-v7a ecc.); se non esiste una directory lib, scrive per tutte le architetture (incluse x86 / x86_64)
  • Nome della classe hook personalizzabile: KillerApplication è rinominabile liberamente, le 12 classi interne vengono rinominate automaticamente tramite dexlib2 per evitare il rilevamento della firma
  • Parametri di iniezione completamente personalizzabili: percorso originale / percorso di estrazione / nome del so / classe hook / informazioni sulla firma / nome della voce, che legge automaticamente i valori reali se lasciati vuoti
  • Non tocca mai i metodi di business: a differenza dei "metodi di controllo azzerati", niente fragili supposizioni su parole chiave/impronte, nessun blocco all'avvio dovuto all'azzeramento del bytecode, con la stessa efficacia di MT Manager
  • Protezione dagli arresti: sia l'iniezione del DEX hook sia la riscrittura della classe padre dell'Application usano backup + scrittura atomica + ripristino automatico

🛡 Nucleo di rimozione pubblicità

  • 18 categorie di funzionalità pubblicitarie: librerie SDK / permessi / classi / metodi / risorse / URL / View / Activity / Service / Receiver, completamente personalizzabili con ripristino
  • Elaborazione AXML approfondita: rimuove i componenti pubblicitari e le dichiarazioni di permessi pubblicitari, nasconde le View pubblicitarie del layout Res
  • Precisione a livello di metodo: azzera i metodi delle classi pubblicitarie, svuota i link pubblicitari e la geometria delle View
  • Sblocco VIP: forza il ritorno true/false per bypassare i giudizi pubblicitari e sbloccare l'abbonamento
  • Pulizia delle risorse pubblicitarie: pulisce automaticamente le librerie native dell'SDK pubblicitario (.so), le risorse pubblicitarie negli assets e i file pubblicitari nella root
  • Supporto Flutter: analizza lo snapshot AOT di Dart e cancella le firme delle stringhe pubblicitarie in libapp.so

📦 Ottimizzazione delle dimensioni

  • Ottimizzazione del riutilizzo dei dati: i pacchetti bypass (ad es. gli artefatti LSPatch) riutilizzano la sezione dati originale, riducendo le dimensioni fino a ~50%
  • Rilevamento degli APK rinominati: riconosce con precisione pacchetti originali rinominati senza estensione o con estensioni arbitrarie
  • Ottimizzazione delle dimensioni DEX: rimuove le informazioni di debug (numeri di riga / tabelle delle variabili locali), riducendo ulteriormente le dimensioni del 5%~15%
  • Compressione intelligente + allineamento ZIP: garantisce che l'APK ripacchettizzato si installi e funzioni normalmente

🔒 Stabilità e sicurezza

  • Doppia firma v1 + v2, compatibile con dispositivi a bassa versione, con risultati installabili direttamente
  • Protezione dagli arresti DEX: backup + scrittura atomica + ripristino automatico
  • Protezione dal path traversal: corregge Zip Slip, blocca gli APK dannosi dallo scrivere fuori dai limiti
  • Scansione a basso consumo di memoria: gestisce DEX enormi in modo stabile senza bloccarsi

🎨 Esperienza

  • Selettore integrato di 17 lingue (novità in v3.5): cinese semplificato/tradizionale, English, 日本語, 한국어, Español, Français, Deutsch, Italiano, Português, Русский, हिन्दी, Tiếng Việt, ไทย, Bahasa Indonesia, العربية, Türkçe; seguendo il sistema o con un cambio con un tocco nell'app, con effetto immediato
  • Log di elaborazione colorato in tempo reale, con copia / pulizia con un tocco
  • Genera automaticamente un report di elaborazione in Markdown
  • Importazione e condivisione della sottoscrizione dei modelli pubblicitari
  • Tema chiaro/scuro duplice (segui il sistema / chiaro / notte)
  • Il testo lungo va automaticamente a capo completamente, senza troncamenti con i puntini di sospensione (copre lingue con parole lunghe come il russo)

🚀 Avvio rapido

Compilazione

# Requirements: Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

L'output si trova in app/build/outputs/apk/release/, direttamente installabile.

Questo progetto include la compilazione automatica GitHub Actions: ogni push/PR compila le versioni Debug e Release; la pubblicazione di un tag v* pubblica automaticamente la Release con gli artefatti APK.

Le note di rilascio sono generate automaticamente da release-drafter: tagga automaticamente le PR in base a titolo/ramo/file modificati (feature/bug/docs/ci ecc.) e riassume un changelog strutturato al rilascio.

Utilizzo

  1. Seleziona l'APK da elaborare (sono supportati gli APK rinominati)
  2. Tocca "Avvia elaborazione": estrazione, rimozione pubblicità, ottimizzazione delle dimensioni, ri-pacchettizzazione e firma automatiche
  3. Esporta automaticamente nella directory originale, generando il report di elaborazione in Markdown

🆕 Novità (v3.5)

  • Interruttore multilingue: 17 lingue, modalità segui il sistema o cambio con un tocco nell'app, con effetto immediato
  • UI completamente esternalizzata: tutti i layout, i menu, i dialoghi e i log unificati come risorse stringa, lingue rigorosamente allineate, testo lungo con andata a capo automatica
  • Corretta la visualizzazione del percorso di esportazione: il log di esportazione non mostra più il segnaposto Exported: %1$s, ma il percorso reale
  • Corretta la rimozione pubblicità multilingue: completa gli argomenti dei segnaposto delle stringhe, eliminando il MissingFormatArgumentException che interrompeva l'elaborazione degli APK dopo il cambio di lingua

La cronologia completa delle versioni è disponibile in CHANGELOG.
