📖 About

One-click full pipeline: unpack → remove ads → bypass signature → size optimization → repack → sign, all processed locally & offline, no network needed.

Instead of the traditional smali disassemble-reassemble flow, it uses direct bytecode patching, which boosts processing speed several times while keeping precision.

✨ Features

🛡 Signature Bypass (new in v3.0)

  • MT Manager-style KillerApplication injection: injects a hook class with 12 inner classes as a standalone DEX, rewrites the target Application's parent class, and at runtime reflection-fills PackageInfo.CREATOR with the original signature, covering most Java-layer signature checks
  • Dual-mode bypass: Normal (inject hooks to cover Java checks) / Original-mode (extra embed origin.apk + native lib to cover native-layer disk re-read signature checks)
  • Smart SO injection: auto-detects target APK ABI, only writes into existing dirs (arm64-v8a / armeabi-v7a etc.); writes all architectures (incl. x86 / x86_64) if no lib dir
  • Custom hook class name: KillerApplication freely renamable, 12 inner classes auto-renamed via dexlib2 to avoid signature detection
  • Fully customizable injection params: original path / extract path / so name / hook class / signature info / entry name, auto-reads real values when blank
  • Never touches business methods: unlike "null-out check methods", no fragile keyword/fingerprint guessing, no startup-freeze from bytecode nulling, same strength as MT Manager
  • Crash guard: hook DEX injection and Application parent rewrite both use backup + atomic write-back + auto recovery

🛡 Ad Removal Core

  • 18 categories of ad features: SDK libs / permissions / classes / methods / resources / URLs / Views / Activities / Services / Receivers, fully customizable with reset
  • Deep AXML processing: removes ad components, ad permission declarations, hides Res-layout ad Views
  • Method-level precision: null-out ad-class methods, blank ad links, blank View geometry
  • VIP unlock: force return true/false to bypass ad judgments and unlock membership
  • Ad resource cleaning: auto-cleans ad SDK native libs (.so), assets ad resources and root ad files
  • Flutter support: parses Dart AOT snapshot, erases ad string signatures in libapp.so

📦 Size Optimization

  • Data reuse optimization: bypass packs (e.g. LSPatch artifacts) reuse original data section, reducing size by up to ~50%
  • Renamed APK detection: accurately recognizes original packs renamed to no-extension or arbitrary extensions
  • DEX size optimization: removes debug info (line numbers / local var tables), further 5%~15% smaller
  • Smart compression + ZIP alignment: ensures repacked APK installs and runs normally

🔒 Stability & Security

  • v1 + v2 dual signing, compatible with low-version devices, results install directly
  • DEX crash guard: backup protection + atomic write + auto recovery
  • Path traversal protection: fixes Zip Slip, blocks malicious APK from writing outside bounds
  • Low-memory scanning: handles huge DEX stably without freezing

🎨 Experience

  • Built-in 17-language switch (new in v3.4): Simplified/Traditional Chinese, English, 日本語, 한국어, Español, Français, Deutsch, Italiano, Português, Русский, हिन्दी, Tiếng Việt, ไทย, Bahasa Indonesia, العربية, Türkçe; follow-system or in-app one-tap switch, instant effect
  • Real-time colored processing log, one-tap copy / clear

  • Ad-pattern subscription import & share
  • Light/dark dual theme (follow system / light / night)
  • Long text auto-wraps fully, no ellipsis truncation (covers long-word languages like Russian)

🚀 Quick Start

Build

# Requirements: Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Output at app/build/outputs/apk/release/, directly installable.

This project has GitHub Actions auto-build: each push/PR compiles Debug & Release; publishing v* tag auto-releases Release with APK artifacts.

Release notes auto-generated by release-drafter: auto-tags PRs by title/branch/changed files (feature/bug/docs/ci etc.), summarizes structured changelog on release.

Usage

  1. Select the APK to process (renamed APKs supported)
  2. Tap "Start Processing": auto unpack, remove ads, optimize size, repack, sign
  3. Auto-export to original directory, generates Markdown processing report

🏗 Architecture

Module Tech Core
DEX patching dexlib2 2.5.2 direct bytecode modification, no disassemble/reassemble
Signature bypass KillerApplication injection MT-style hook injection + Application parent rewrite + reflection re-fill
AXML handler in-house parser parses AXML chunks, removes ad components & permissions
Data reuse ApkDataMultiplexing central-dir offset reuse of original data section
Signing apksig + V2V3SchemeSigner v1/v2 dual signing, dedicated sign after optimization
Flutter Dart AOT snapshot erases ad string signatures in libapp.so
Packing in-house ZIP engine smart compress + align + crash guard
