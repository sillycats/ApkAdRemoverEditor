📖 Acerca del proyecto

Flujo completo en un clic: desempaquetar → eliminar anuncios → evadir firma → optimizar tamaño → reempaquetar → firmar, todo procesado local y sin conexión, sin necesidad de red.

A diferencia del proceso tradicional de desensamblado y reensamblado de smali, usa parcheo directo de bytecode, lo que aumenta varias veces la velocidad de procesamiento manteniendo la precisión.

✨ Características

🛡 Evasión de firma (nuevo en v3.0)

  • Inyección KillerApplication al estilo MT Manager: inyecta una clase hook con 12 clases internas como DEX independiente, reescribe la clase padre del Application objetivo y en tiempo de ejecución rellena por reflexión PackageInfo.CREATOR con la firma original, cubriendo la mayoría de las verificaciones de firma de la capa Java
  • Evasión dual: Normal (inyectar hooks para capa Java) / Original (reforzada, incrusta origin.apk + librería nativa para cubrir también la capa nativa de relectura de firma)
  • Inyección SO inteligente: detecta automáticamente la ABI del APK y solo escribe en directorios existentes (arm64-v8a / armeabi-v7a, etc.); si no hay directorio lib, escribe para todas las arquitecturas (incl. x86 / x86_64)
  • Nombre de clase hook personalizable: KillerApplication se puede renombrar libremente; las 12 clases internas se renombran automáticamente con dexlib2 para evitar la detección
  • Parámetros de inyección totalmente personalizables: ruta original / ruta de extracción / nombre del so / clase hook / información de firma / nombre de entrada; si se dejan en blanco, se leen los valores reales
  • No toca métodos de negocio: a diferencia de "anular métodos de verificación", no depende de suposiciones frágiles de palabras clave/huellas, sin congelación de arranque por anulación de bytecode, con la misma solidez que MT Manager
  • Protección contra fallos: tanto la inyección del DEX hook como la reescritura de la clase padre de Application usan copia de seguridad + escritura atómica + recuperación automática

🛡 Núcleo de eliminación de anuncios

  • 18 categorías de características publicitarias: bibliotecas SDK / permisos / clases / métodos / recursos / URLs / Views / Activities / Services / Receivers, totalmente personalizables con reinicio
  • Procesamiento profundo de AXML: elimina componentes publicitarios, declaraciones de permisos de anuncios, oculta Views de anuncios del layout Res
  • Precisión a nivel de método: anula métodos de clases publicitarias, vacía enlaces publicitarios, vacía geometría de Views
  • Desbloqueo premium: fuerza devolver true/false para desbloquear funciones de pago y bloquear la detección de anuncios
  • Limpieza de recursos publicitarios: limpia automáticamente librerías nativas de SDK de anuncios (.so), recursos publicitarios de assets y archivos publicitarios raíz
  • Compatibilidad con Flutter: analiza la instantánea AOT de Dart y borra las firmas de cadenas publicitarias en libapp.so

📦 Optimización de tamaño

  • Optimización de reutilización de datos: los paquetes evadidos (como artefactos de LSPatch) reutilizan la sección de datos original, reduciendo el tamaño hasta ~50%
  • Detección de APK renombrado: reconoce con precisión paquetes originales renombrados sin extensión o con extensión arbitraria
  • Optimización de tamaño DEX: elimina información de depuración (números de línea/tablas de variables locales), reduciendo otro 5%~15%
  • Compresión inteligente + alineación ZIP: garantiza que el APK reempaquetado se instale y ejecute con normalidad

🔒 Estabilidad y seguridad

  • Doble firma v1 + v2, compatible con dispositivos de baja versión, se instala directamente
  • Protección contra fallos DEX: copia de seguridad + escritura atómica + recuperación automática
  • Protección contra path traversal: corrige Zip Slip, bloquea escrituras fuera de límites de APK maliciosos
  • Escaneo de poca memoria: maneja DEX enormes de forma estable sin congelarse

🎨 Experiencia

  • Interruptor de 17 idiomas integrado (nuevo en v3.5): 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Español / Français / Deutsch / Italiano / Português / Русский / हिन्दी / Tiếng Việt / ไทย / Bahasa Indonesia / العربية / Türkçe; modo "seguir sistema" o cambio con un toque, efecto inmediato
  • Registro de procesamiento en color en tiempo real, con copia / borrado con un toque
  • Genera automáticamente informe Markdown de procesamiento
  • Importación y compartición de suscripciones de patrones publicitarios
  • Tema claro/oscuro (seguir sistema / claro / noche)
  • El texto largo se ajusta automáticamente y se muestra completo, sin elipsis truncada (incluye idiomas de palabras largas como el ruso)

🚀 Inicio rápido

Compilar

# Requisitos: Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Los artefactos están en app/build/outputs/apk/release/, listos para instalar.

Este proyecto tiene GitHub Actions de compilación automática: cada push/PR compila Debug y Release; al publicar etiqueta v* se publica Release automáticamente con los APK.

Las notas de versión las genera release-drafter: etiqueta los PR automáticamente por título/rama/archivos (feature/bug/docs/ci, etc.) y agrega un changelog estructurado al publicar.

Uso

  1. Selecciona el APK a procesar (compatible con APK renombrados)
  2. Toca "Iniciar procesamiento": desempaqueta, elimina anuncios, optimiza tamaño, reempaqueta y firma automáticamente
  3. Al terminar se exporta al directorio original y genera el informe Markdown

🆕 Novedades (v3.5)

  • Interruptor multilingüe: 17 idiomas, modo "seguir sistema" o cambio en la app, efecto inmediato
  • UI totalmente externalizada: todos los layouts, menús, diálogos y registros unificados como recursos de cadena, idiomas alineados, texto largo ajustado
  • Corrección de ruta de exportación: el registro ya no muestra el marcador %1$s, muestra la ruta real
  • Corrección de eliminación multilingüe: completa los argumentos de marcadores, elimina el MissingFormatArgumentException que rompía el procesamiento tras cambiar idioma

El historial completo en CHANGELOG.
