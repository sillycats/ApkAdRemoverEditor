📖 專案簡介

一鍵完成 解包 → 去廣告 → 過簽 → 體積最佳化 → 打包 → 簽名 全流程，全程本地離線處理，無需網路。

有別於傳統 smali 反組譯-回組譯流程，採用位元組碼直接修補方案，在保證處理精度的同時將處理速度提升數倍。

✨ 功能特色

🛡 過簽能力（v3.0 新增）

  • MT 管理器式 KillerApplication 注入過簽：注入含 12 個內部類別的鉤子類別為獨立 DEX，改寫目標應用 Application 父類別，執行時期反射替換 PackageInfo.CREATOR 回填原包簽名，涵蓋大多數 Java 層簽名校驗
  • 雙模式過簽：普通去除（僅注入鉤子涵蓋 Java 層校驗）/ 原包去除（增強，額外嵌入 origin.apk + 原生庫，涵蓋磁碟 APK 重新讀取簽名的原生層校驗）
  • SO 智慧注入：自動辨識目標 APK 的 ABI 架構，僅寫入已存在的目錄（arm64-v8a / armeabi-v7a 等）；無 lib 目錄則全架構寫入（含 x86 / x86_64）
  • 鉤子類別名可自訂：KillerApplication 名稱自由修改，內建 12 個內部類別基於 dexlib2 自動同步重新命名，避免特徵被偵測
  • 注入參數全面可自訂：原包路徑 / 解壓路徑 / So庫名 / 鉤子類別名 / 簽名資訊 / 入口名稱，留空自動讀取真實值
  • 不碰觸業務方法：相較"置空校驗方法"方案，不依賴脆弱的關鍵字/指紋臆測，不產生位元組碼置空導致的啟動卡死，過簽強度與 MT 管理器一致
  • 當機防護：鉤子 DEX 注入與 Application 父類別改寫均採用備份 + 原子寫回 + 例外自動復原

🛡 去廣告核心

  • 18 類廣告特徵全覆蓋：SDK 庫 / 權限 / 類別 / 方法 / 資源 / URL / View / Activity / Service / Receiver，可自訂增刪改查與一鍵重設
  • AXML 深度處理：移除廣告元件、廣告權限宣告、隱藏 Res 佈局廣告 View
  • 方法級精準處理：廣告類別方法置空、廣告連結置空、View 幾何置空
  • 會員功能解鎖：強制回傳 true/false，解密會員功能並屏蔽廣告判定
  • 廣告資源清理：自動清理廣告 SDK 原生庫 (.so)、assets 廣告資源與根目錄廣告檔案
  • Flutter 應用適配：解析 Dart AOT 快照，抹除 libapp.so 中的廣告字串特徵

📦 體積最佳化

  • 資料重用最佳化：過簽包（如 LSPatch 產物）重用原包資料段，最多縮小約 50% 體積
  • 重新命名辨識：原包被重新命名為無後綴或任意後綴也能精確辨識並最佳化
  • DEX 體積最佳化：移除除錯資訊（行號/區域變數表），再縮小 5%~15% 體積
  • 智慧壓縮策略 + ZIP 對齊：保證打包後 APK 正常安裝啟動

🔒 穩定性與安全

  • v1 + v2 雙簽名，相容低版本裝置，處理結果可直接安裝
  • DEX 當機防護：備份保護 + 原子寫入 + 例外自動復原
  • 路徑穿越防護：修復 Zip Slip 漏洞，杜絕惡意 APK 越界寫檔案
  • 低記憶體掃描：超大 DEX 也能穩定處理不卡死

🎨 使用體驗

  • 內建 17 種語言切換（v3.4 新增）：支援簡體中文 / 繁體中文 / English / 日本語 / 한국어 / Español / Français / Deutsch / Italiano / Português / Русский / हिन्दी / Tiếng Việt / ไทย / Bahasa Indonesia / العربية / Türkçe，可"跟隨系統"或在應用內一鍵切換並即時生效
  • 即時彩色處理日誌，支援一鍵複製 / 清空
  • 自動產生 Markdown 處理報告
  • 廣告特徵訂閱匯入與分享
  • 明暗雙主題（跟隨系統 / 白天 / 夜間）
  • 長文字自動換行完整顯示，杜絕省略號截斷（涵蓋俄語等長單詞語言）

🚀 快速上手

編譯

# 環境需求：Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

產物位於 app/build/outputs/apk/release/，可直接安裝使用。

本專案已設定 GitHub Actions 自動建置：每次 push / PR 自動編譯 Debug 與 Release 包；打 v* 標籤時自動發布 Release 並附帶 APK 產物。

發布說明由 release-drafter 自動產生：會根據 PR 標題 / 分支 / 改動檔案自動打標籤（feature / bug / docs / ci 等），發布時自動按分類彙總為結構化更新日誌。

使用

  1. 選擇需要處理的 APK 檔案（支援重新命名後的 APK）
  2. 點擊"開始處理"，自動完成解包、去廣告、體積最佳化、打包、簽名
  3. 處理完成自動匯出到原包目錄，並產生 Markdown 處理報告

🆕 版本更新（v3.4）

  • 多國語言切換：支援 17 種語言，可"跟隨系統"或應用內一鍵切換即時生效
  • 介面全量外置化：所有佈局、選單、彈窗、日誌文案統一為字串資源，各語言資源嚴格對齊，長文字自動換行完整顯示
  • 修復匯出路徑顯示：匯出完成日誌不再顯示 已匯出: %1$s 佔位符，改為真實路徑
  • 修復多語言去廣告：補齊字串佔位符實參，杜絕切換語言後無法去廣告處理 APK 的 MissingFormatArgumentException

完整的版本記錄請參見 CHANGELOG。
