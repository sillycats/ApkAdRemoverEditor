📖 حول المشروع

مسار كامل بنقرة واحدة : فك الضغط → إزالة الإعلانات → تجاوز التوقيع → تحسين الحجم → إعادة التعبئة → التوقيع، وكل ذلك محليًا دون اتصال ولا يحتاج إلى شبكة.

بدلاً من أسلوب smali التقليدي (التفكيك ثم إعادة التركيب)، يستخدم التصحيح المباشر للبايت كود، مما يسرّع المعالجة عدة مرات مع الحفاظ على الدقة.

✨ المزايا

🛡 تجاوز التوقيع (جديد في v3.0)

  • حقن KillerApplication بأسلوب MT Manager : يحقن فئة خطاف تضم 12 فئة داخلية كـ DEX مستقل، ويعيد كتابة الفئة الأصلية للـ Application، ويملأ وقت التشغيل عبر الانعكاس PackageInfo.CREATOR بالتوقيع الأصلي، ويغطي معظم تحققات Java
  • نمط مزدوج : عادي (خطافات لطبقة Java) / أصلي (معزّز، يتضمن origin.apk + مكتبة أصلية لطبقة التوقيع الأصلية)
  • حقن SO ذكي : يكتشف ABI ويكتب فقط في المجلدات الموجودة (arm64-v8a / armeabi-v7a...) ; إن لم يوجد lib يكتب لكل البنى (بما فيها x86 / x86_64)
  • اسم فئة الخطاف قابل للتخصيص : يمكن إعادة تسمية KillerApplication، وتُعاد تسمية الفئات الـ 12 تلقائيًا عبر dexlib2
  • معاملات الحقن قابلة للتخصيص : مسار الأصلي / فك الضغط / اسم so / فئة الخطاف / التوقيع / نقطة الدخول؛ فارغ = قراءة القيم الحقيقية
  • لا يلمس أساليب العمل : لا فرضيات هشة، لا تجمّد عند الإقلاع، بنفس قوة MT Manager
  • حماية من الأعطال : نسخة احتياطية + كتابة ذرّية + استعادة تلقائية

🛡 إزالة الإعلانات

  • 18 فئة من سمات الإعلانات : مكتبات SDK / الأذونات / الفئات / الأساليب / الموارد / الروابط / Views / Activities / Services / Receivers، قابلة للتخصيص مع إعادة تعيين
  • معالجة AXML عميقة : إزالة عناصر الإعلان والأذونات وإخفاء Views الإعلان
  • دقة على مستوى الأسلوب : إفراغ أساليب الفئات الإعلانية والروابط والهندسة
  • فتح الميزات المدفوعة : إجبار true/false لتجاوز إعلانات
  • تنظيف موارد الإعلانات : مكتبات SDK الأصلية (.so)، موارد assets، ملفات الجذر
  • دعم Flutter : تحليل لقطة Dart AOT، ومسح توقيعات السلاسل في libapp.so

📦 تحسين الحجم

  • إعادة استخدام البيانات : الحزم المتجاوزة (مثل نواتج LSPatch) تعيد استخدام مقطع البيانات الأصلي حتى ~50 %
  • اكتشاف APK أُعيدت تسميته : بدون امتداد أو بأي امتداد
  • تحسين DEX : إزالة معلومات التصحيح، 5 %–15 % إضافية
  • ضغط ذكي + محاذاة ZIP : ضمان تثبيت صحيح

🔒 الاستقرار والأمان

  • توقيع مزدوج v1 + v2، متوافق مع الأجهزة القديمة
  • حماية أعطال DEX : نسخة احتياطية + كتابة ذرّية + استعادة
  • حماية من اجتياز المسار : إصلاح Zip Slip، منع الكتابة خارج النطاق
  • مسح منخفض الذاكرة : معالجة DEX الكبيرة دون تجمّد

🚀 البدء السريع

البناء

# المتطلبات : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

المخرجات في app/build/outputs/apk/release/، قابلة للتثبيت مباشرة.

المشروع مزود بـ GitHub Actions للبناء التلقائي : كل push/PR يبني Debug & Release ; نشر وسم v* ينشر Release مع APK.

ملاحظات الإصدار عبر release-drafter : وسوم تلقائية حسب العنوان/الفرع/الملفات وتجميع سجل منظم.

الاستخدام

  1. اختر APK (يدعم المُعاد تسميته)
  2. اضغط «ابدأ» : فك الضغط، إزالة، تحسين، تعبئة، توقيع
  3. تصدير إلى المجلد الأصلي + تقرير Markdown

🆕 ما الجديد (v3.4)

  • مفتاح متعدد اللغات : 17 لغة، «تبع النظام» أو في التطبيق فورًا
  • الواجهة كاملة في الموارد : كل التخطيطات والقوائم والحوارات والسجلات
  • إصلاح مسار التصدير : لا ماركر %1$s بل مسار حقيقي
  • إصلاح إزالة الإعلانات متعددة اللغات : استكمال الوسائط، إزالة MissingFormatArgumentException
