📥 다운로드 및 설치

Releases 페이지에서 최신 APK를 다운로드하거나 다음 채널 중 하나를 이용하세요:

  • 프로젝트 홈: https://sillycats.github.io/ApkAdRemoverEditor/
  • GitHub Releases: https://github.com/sillycats/ApkAdRemoverEditor/releases
  • 자동 빌드: 커밋마다 GitHub Actions가 자동 컴파일하며, 산출물은 CI 빌드 로그에서 받을 수 있음
  • 커뮤니티: https://github.com/sillycats/ApkAdRemoverEditor/discussions

설치 시 "알 수 없는 소스" 안내가 나오면 시스템 설정에서 이 소스의 앱 설치를 허용하세요.

📖 프로젝트 소개

풀기 → 광고 제거 → 서명 우회 → 크기 최적화 → 다시 패킹 → 서명 전체 과정을 원클릭으로 처리하며, 모든 작업은 로컬에서 오프라인으로 진행되어 네트워크가 필요 없습니다.

기존 smali 역어셈블-재어셈블 방식 대신 바이트코드 직접 패치 방식을 채택해, 처리 정확도를 유지하면서 속도를 수 배 향상시킵니다.

✨ 기능

🛡 서명 우회 (v3.0 추가)

  • MT Manager식 KillerApplication 주입: 12개의 내부 클래스를 포함한 훅 클래스를 독립 DEX로 주입하고, 대상 애플리케이션의 Application 부모 클래스를 재작성하며, 런타임에 PackageInfo.CREATOR를 리플렉션으로 채워 원본 서명을 복원. 대부분의 Java 계층 서명 검사를 처리
  • 이중 모드 우회: 일반(훅 주입으로 Java 계층 검사 처리) / 원본(강화: origin.apk + 네이티브 라이브러리를 추가로 내장해 네이티브 계층 서명 재확인까지 처리)
  • SO 스마트 주입: 대상 APK의 ABI를 자동 감지해 기존 디렉토리(arm64-v8a / armeabi-v7a 등)에만 기록. lib 디렉토리가 없으면 전체 아키텍처(x86 / x86_64 포함)에 기록
  • 훅 클래스 이름 커스터마이즈: KillerApplication 이름을 자유롭게 변경 가능하며, 12개 내부 클래스는 dexlib2 기반으로 자동 동기 리네임되어 탐지 회피
  • 주입 파라미터 완전 커스터마이즈: 원본 경로 / 압축 해제 경로 / so 라이브러리명 / 훅 클래스명 / 서명 정보 / 엔트리 이름. 비워두면 실제 값을 자동으로 읽음
  • 비즈니스 메서드에 손대지 않음: "검사 메서드 비우기" 방식과 달리 취약한 키워드/지문 추측에 의존하지 않고, 바이트코드 널링으로 인한 시작 멈춤도 없으며, MT Manager와 동일한 강도
  • 크래시 보호: 훅 DEX 주입과 Application 부모 재작성 모두 백업 + 원자적 기록 + 예외 시 자동 복구

🛡 광고 제거 코어

  • 18개 카테고리 광고 특징 커버: SDK 라이브러리 / 권한 / 클래스 / 메서드 / 리소스 / URL / View / Activity / Service / Receiver. 사용자 정의와 원클릭 리셋 지원
  • AXML 심층 처리: 광고 컴포넌트, 광고 권한 선언 제거, Res 레이아웃 광고 View 숨김
  • 메서드 수준 정밀 처리: 광고 클래스 메서드 비우기, 광고 링크 비우기, View 기하 비우기
  • 멤버십 기능 해제: true/false를 강제 반환해 멤버십 기능을 해제하고 광고 판정을 차단
  • 광고 리소스 정리: 광고 SDK 네이티브 라이브러리(.so), assets 광고 리소스, 루트 광고 파일 자동 정리
  • Flutter 지원: Dart AOT 스냅샷을 분석해 libapp.so 안의 광고 문자열 특징을 제거

📦 크기 최적화

  • 데이터 재사용 최적화: 우회 패키지(예: LSPatch 산출물)가 원본 데이터 섹션을 재사용해 최대 약 50% 크기 감소
  • 리네임된 APK 감지: 확장자 없음 또는 임의 확장자로 리네임된 원본도 정확히 감지해 최적화
  • DEX 크기 최적화: 디버그 정보(줄 번호/로컬 변수 테이블) 제거로 추가 5%~15% 감소
  • 스마트 압축 + ZIP 정렬: 다시 패킹된 APK가 정상적으로 설치·실행되도록 보장

🔒 안정성과 보안

  • v1 + v2 이중 서명, 저사양 기기와 호환, 처리 결과 그대로 설치 가능
  • DEX 크래시 보호: 백업 보호 + 원자적 기록 + 예외 자동 복구
  • 경로 순회 보호: Zip Slip을 수정해 악성 APK의 범위 밖 파일 기록을 차단
  • 저메모리 스캔: 초대형 DEX도 멈춤 없이 안정적으로 처리

🚀 빠른 시작

빌드

# 요구사항: Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

산출물은 app/build/outputs/apk/release/에 있으며 바로 설치할 수 있습니다.

이 프로젝트는 GitHub Actions 자동 빌드를 설정했습니다: push / PR마다 Debug 및 Release를 자동 컴파일하고, v* 태그를 만들면 Release를 자동 게시하며 APK 산출물을 첨부합니다.

릴리즈 노트는 release-drafter가 PR 제목 / 브랜치 / 변경 파일에 따라 자동 태그(feature / bug / docs / ci 등)를 매기고, 게시 시 카테고리별 구조화된 업데이트 로그로 자동 집계합니다.

사용

  1. 처리할 APK 파일 선택(리네임된 APK 지원)
  2. "처리 시작" 탭: 풀기, 광고 제거, 크기 최적화, 패킹, 서명을 자동 실행
  3. 완료 후 원본 디렉토리에 자동 내보내기, Markdown 처리 리포트 생성

🆕 버전 업데이트 (v3.4)

  • 다국어 전환: 17개 언어 지원. "시스템 따라가기" 또는 앱 내 원클릭 전환, 즉시 반영
  • UI 완전 리소스화: 모든 레이아웃, 메뉴, 다이얼로그, 로그 문구를 문자열 리소스로 통일하고, 각 언어 리소스를 엄격히 맞추며 긴 텍스트를 자동 줄바꿈으로 완전 표시
  • 내보내기 경로 표시 수정: 완료 로그가 %1$s 자리표시자가 아닌 실제 경로를 표시
  • 다국어 광고 제거 수정: 문자열 자리표시자 실인자를 보완해, 언어 전환 후 MissingFormatArgumentException으로 APK 처리가 실패하는 문제 해결

전체 버전 기록은 CHANGELOG를 참고하세요.
