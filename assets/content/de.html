📖 Über das Projekt

Ein-Klick-Pipeline : Entpacken → Werbung entfernen → Signatur umgehen → Größe optimieren → neu packen → signieren, alles lokal und offline, ohne Netzwerk.

Statt des traditionellen smali-Disassemble-Reassemble nutzt es direktes Bytecode-Patching, was die Verarbeitung bei gleicher Präzision mehrfach beschleunigt.

✨ Funktionen

🛡 Signatur-Umgehung (neu in v3.0)

  • KillerApplication-Injektion nach MT-Manager-Art : injiziert eine Hook-Klasse mit 12 inneren Klassen als eigenes DEX, überschreibt die Application-Parentklasse und füllt zur Laufzeit per Reflexion PackageInfo.CREATOR mit der Originalsignatur, deckt die meisten Java-Signaturprüfungen ab
  • Doppel-Modus : Normal (Hooks für Java-Ebene) / Original (verstärkt, mit origin.apk + nativer Lib für die native Ebene)
  • Intelligente SO-Injektion : erkennt die ABI, schreibt nur in vorhandene Verzeichnisse (arm64-v8a / armeabi-v7a...) ; ohne lib alle Architekturen (inkl. x86 / x86_64)
  • Hook-Klassenname frei wählbar : KillerApplication frei umbenennbar, 12 innere Klassen via dexlib2 automatisch umbenannt
  • Injektionsparameter frei konfigurierbar : Originalpfad / Extraktionspfad / so-Name / Hook-Klasse / Signatur / Eintrag ; leer = echte Werte
  • Fasst Business-Methoden nicht an : keine fragilen Keyword-Fingerprints, kein Start-Freeze, gleiche Stärke wie MT Manager
  • Crash-Schutz : Backup + atomares Schreiben + automatische Wiederherstellung

🛡 Werbeentfernung

  • 18 Kategorien von Werbemerkmalen : SDK-Libs / Permissions / Klassen / Methoden / Ressourcen / URLs / Views / Activities / Services / Receivers, frei konfigurierbar mit Reset
  • Tiefes AXML-Handling : entfernt Werbekomponenten, -permissions, blendet Werbe-Views aus
  • Methodenpräzision : Methode der Werbeklasse nullen, Links leeren, Geometrie leeren
  • Premium-Funktionen : erzwingt true/false zum Entsperren
  • Werbungsressourcen-Reinigung : native SDK-Libs (.so), assets, root-Dateien
  • Flutter-Support : analysiert Dart-AOT-Snapshot, löscht Zeichenketten-Signaturen in libapp.so

📦 Größenoptimierung

  • Daten-Wiederverwendung : umgangene Pakete (z. B. LSPatch-Artefakte) nutzen den Original-Datenbereich, bis zu ~50 % kleiner
  • Umbenannte APKs erkennen : erkennt APKs ohne oder mit beliebiger Endung
  • DEX-Optimierung : Debug-Infos entfernen, weitere 5 %~15 %
  • Smart-Kompression + ZIP-Alignment : garantiert korrekte Installation

🔒 Stabilität & Sicherheit

  • Doppel-Signatur v1 + v2, kompatibel mit alten Geräten
  • DEX-Crash-Schutz : Backup + atomares Schreiben + Wiederherstellung
  • Path-Traversal-Schutz : behebt Zip Slip, blockt missbräuchliche Schreibvorgänge
  • Low-Memory-Scan : verarbeitet riesige DEX ohne Einfrieren

🚀 Schnellstart

Build

# Voraussetzung : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Artefakte in app/build/outputs/apk/release/, direkt installierbar.

Dieses Projekt hat GitHub Actions Auto-Build : jeder Push/PR kompiliert Debug & Release ; v*-Tag veröffentlicht Release mit APKs.

Release-Notes via release-drafter : taggt PRs nach Titel/Branch/Dateien und aggregiert strukturierten Changelog.

Verwendung

  1. APK auswählen (umbenannte unterstützt)
  2. "Start" antippen : Entpacken, Entfernen, Optimieren, Packen, Signieren
  3. Export in Originalverzeichnis + Markdown-Report

🆕 Neuerungen (v3.5)

  • Mehrsprachiger Schalter : 17 Sprachen, "System folgen" oder in der App, sofort
  • UI vollständig externalisiert : alle Layouts, Menüs, Dialoge, Logs als Ressourcen
  • Exportpfad korrigiert : kein %1$s-Marker mehr, echter Pfad
  • Mehrsprachige Werbeentfernung korrigiert : Argumente ergänzt, MissingFormatArgumentException behoben

Gesamte Historie in CHANGELOG.

🏗 Architektur

Modul Technik Beschreibung
DEX-Patch-Engine dexlib2 2.5.2 direkte Bytecode-Modifikation
Signatur-Umgehung KillerApplication-Injektion MT-Hook + Application-Override + Reflexion
AXML-Prozessor eigener Parser Chunks analysieren, Komponenten entfernen
Wiederverwendung ApkDataMultiplexing Original-Datenbereich nutzen
Signatur apksig + V2V3SchemeSigner doppelte v1/v2
Flutter Dart-AOT-Snapshot Strings in libapp.so löschen
Packen eigener ZIP-Engine Kompression + Alignment + Schutz
