📖 Giới thiệu

Quy trình trọn gói một chạm : giải nén → gỡ quảng cáo → bypass chữ ký → tối ưu kích thước → đóng gói lại → ký, tất cả xử lý cục bộ và ngoại tuyến, không cần mạng.

Thay vì quy trình smali truyền thống, công cụ dùng patch bytecode trực tiếp, tăng tốc xử lý nhiều lần trong khi vẫn chính xác.

✨ Tính năng

🛡 Bypass chữ ký (mới ở v3.0)

  • Chèn KillerApplication kiểu MT Manager : chèn lớp hook với 12 lớp bên trong thành DEX độc lập, viết lại lớp cha của Application và lúc chạy điền PackageInfo.CREATOR bằng chữ ký gốc qua phản chiếu, bao phủ hầu hết kiểm tra Java
  • Hai chế độ : Thường (hook cho tầng Java) / Gốc (nâng cấp, kèm origin.apk + thư viện native cho tầng native)
  • Chèn SO thông minh : tự nhận ABI, chỉ ghi vào thư mục tồn tại (arm64-v8a / armeabi-v7a...) ; không có lib thì ghi mọi kiến trúc (gồm x86 / x86_64)
  • Tên lớp hook tùy chỉnh : KillerApplication tự đổi tên, 12 lớp bên trong tự đổi theo qua dexlib2
  • Tham số chèn tùy chỉnh hoàn toàn : đường dẫn gốc / giải nén / tên so / lớp hook / chữ ký / điểm vào ; để trống = đọc giá trị thực
  • Không đụng phương thức nghiệp vụ : không phỏng đoán mong manh, không đứng máy lúc khởi động, mạnh như MT Manager
  • Bảo vệ crash : sao lưu + ghi nguyên tử + tự phục hồi

🛡 Lõi gỡ quảng cáo

  • 18 loại đặc trưng quảng cáo : thư viện SDK / quyền / lớp / phương thức / tài nguyên / URL / Views / Activities / Services / Receivers, tùy chỉnh được kèm reset
  • Xử lý AXML sâu : gỡ thành phần, quyền, ẩn View quảng cáo
  • Chính xác cấp phương thức : xóa trắng phương thức lớp quảng cáo, liên kết, hình học
  • Mở khóa premium : ép true/false để bỏ qua quảng cáo
  • Dọn tài nguyên quảng cáo : thư viện native SDK (.so), tài nguyên assets, file gốc
  • Hỗ trợ Flutter : phân tích snapshot AOT Dart, xóa dấu chuỗi trong libapp.so

📦 Tối ưu kích thước

  • Tái dùng dữ liệu : gói bypass (ví dụ thành phẩm LSPatch) tái dùng đoạn dữ liệu gốc, giảm tới ~50 %
  • Nhận APK bị đổi tên : không đuôi hay đuôi bất kỳ
  • Tối ưu DEX : xóa thông tin debug, thêm 5 %–15 %
  • Nén thông minh + căn chỉnh ZIP : đảm bảo cài đặt đúng

🔒 Ổn định & bảo mật

  • Ký đôi v1 + v2, tương thích máy cũ
  • Bảo vệ crash DEX : sao lưu + ghi nguyên tử + phục hồi
  • Chống path traversal : sửa Zip Slip, chặn ghi vượt biên
  • Quét ít RAM : DEX lớn vẫn ổn định không treo

🚀 Bắt đầu nhanh

Build

# Yêu cầu : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Sản phẩm trong app/build/outputs/apk/release/, cài trực tiếp được.

Dự án có GitHub Actions build tự động : mỗi push/PR biên dịch Debug & Release ; gắn tag v* tự phát hành Release kèm APK.

Ghi chú phát hành qua release-drafter : tự gắn nhãn PR theo tiêu đề/nhánh/file và tổng hợp changelog.

Sử dụng

  1. Chọn APK (hỗ trợ APK bị đổi tên)
  2. Nhấn "Bắt đầu" : giải nén, gỡ, tối ưu, đóng gói, ký
  3. Xuất ra thư mục gốc + báo cáo Markdown

🆕 Mới ở v3.4

  • Công tắc đa ngôn ngữ : 17 ngôn ngữ, "theo hệ thống" hoặc trong app, tức thì
  • UI hoàn toàn thành tài nguyên : mọi layout, menu, dialog, log
  • Sửa đường dẫn xuất : không marker %1$s, đường dẫn thật
  • Sửa gỡ quảng cáo đa ngôn ngữ : bổ sung tham số, loại bỏ MissingFormatArgumentException

Lịch sử đầy đủ trong CHANGELOG.
