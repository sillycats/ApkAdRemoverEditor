📖 เกี่ยวกับโครงการ

ขั้นตอนครบวงจรในคลิกเดียว : แกะ → เอาโฆษณาออก → bypass ลายเซ็น → ปรับขนาด → แพ็กใหม่ → เซ็น, ทั้งหมดประมวลผลในเครื่องและออฟไลน์ ไม่ต้องใช้เน็ต

ต่างจากวิธี smali แบบดั้งเดิม เครื่องมือนี้ใช้ การแก้ไบต์โค้ดโดยตรง ซึ่งทำให้ประมวลผลเร็วขึ้นหลายเท่าในขณะที่แม่นยำ

✨ คุณสมบัติ

🛡 Bypass ลายเซ็น (ใหม่ใน v3.0)

  • ฉีด KillerApplication แบบ MT Manager : ฉีดคลาส hook ที่มี 12 คลาสภายในเป็น DEX อิสระ เขียนคลาสพ่อของ Application ใหม่ และตอนรันไทม์เติม PackageInfo.CREATOR ด้วยลายเซ็นเดิมผ่าน reflection ครอบคลุมการตรวจ Java ส่วนใหญ่
  • โหมดคู่ : ปกติ (hook สำหรับชั้น Java) / ต้นฉบับ (เสริมด้วย origin.apk + ไลบรารี native สำหรับชั้น native)
  • ฉีด SO อัจฉริยะ : ตรวจจับ ABI เขียนเฉพาะไดเรกทอรีที่มีอยู่ (arm64-v8a / armeabi-v7a...) ; ไม่มี lib เขียนทุกสถาปัตยกรรม (รวม x86 / x86_64)
  • เปลี่ยนชื่อคลาส hook ได้ : KillerApplication เปลี่ยนชื่อได้อิสระ 12 คลาสในเปลี่ยนตามอัตโนมัติผ่าน dexlib2
  • พารามิเตอร์ฉีดปรับได้ทั้งหมด : พาธต้นฉบับ / แกะ / ชื่อ so / คลาส hook / ลายเซ็น / จุดเข้า ; เว้นว่าง = อ่านค่าจริง
  • ไม่แตะเมธอดธุรกิจ : ไม่มีสมมติฐานเปราะ ไม่ค้างตอนเปิด หนักแน่นเท่า MT Manager
  • กัน crash : สำรอง + เขียนอะตอมมิก + กู้คืนอัตโนมัติ

🛡 แกนเอาโฆษณาออก

  • 18 หมวดคุณสมบัติโฆษณา : ไลบรารี SDK / สิทธิ์ / คลาส / เมธอด / ทรัพยากร / URL / Views / Activities / Services / Receivers ปรับได้พร้อมรีเซ็ต
  • ประมวลผล AXML ลึก : ลบคอมโพเนนต์โฆษณา สิทธิ์ ซ่อน View โฆษณา
  • แม่นระดับเมธอด : ล้างเมธอดคลาสโฆษณา ลิงก์ รูปทรง
  • ปลดล็อกพรีเมียม : บังคับ true/false เพื่อเลี่ยงโฆษณา
  • ทำความสะอาดทรัพยากรโฆษณา : ไลบรารี native (.so) ทรัพยากร assets ไฟล์ราก
  • รองรับ Flutter : วิเคราะห์ snapshot AOT ของ Dart ลบลายเซ็นสตริงใน libapp.so

📦 ปรับขนาด

  • ใช้ข้อมูลซ้ำ : แพ็กที่ bypass (เช่น ผลงาน LSPatch) ใช้ส่วนข้อมูลเดิม ลดได้ถึง ~50 %
  • ตรวจจับ APK ที่เปลี่ยนชื่อ : ไม่มีนามสกุลหรือนามสกุลใดก็ได้
  • ปรับ DEX : ลบข้อมูล debug อีก 5 %–15 %
  • บีบอัดอัจฉริยะ + จัดแนว ZIP : รับประกันติดตั้งถูกต้อง

🔒 เสถียรภาพและความปลอดภัย

  • เซ็นคู่ v1 + v2 เข้ากับเครื่องเก่า
  • กัน crash DEX : สำรอง + เขียนอะตอมมิก + กู้คืน
  • กัน path traversal : แก้ Zip Slip ปิดกั้นการเขียนเกินขอบเขต
  • สแกนใช้หน่วยความจำต่ำ : DEX ใหญ่ยังเสถียรไม่ค้าง

🚀 เริ่มต้นเร็ว

Build

# ความต้องการ : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

ไฟล์ใน app/build/outputs/apk/release/ ติดตั้งได้ทันที

โครงการมี GitHub Actions build อัตโนมัติ : ทุก push/PR คอมไพล์ Debug & Release ; ตั้ง tag v* เผยแพร่ Release พร้อม APK

บันทึกเวอร์ชันผ่าน release-drafter : ติดแท็ก PR อัตโนมัติตามชื่อ/สาขา/ไฟล์ และรวม changelog

การใช้งาน

  1. เลือก APK (รองรับที่เปลี่ยนชื่อแล้ว)
  2. กด "เริ่ม" : แกะ เอาโฆษณา ปรับ แพ็ก เซ็น
  3. ส่งออกไปโฟลเดอร์เดิม + รายงาน Markdown

🆕 ใหม่ใน v3.4

  • สวิตช์หลายภาษา : 17 ภาษา "ตามระบบ" หรือในแอป ทันที
  • UI เป็นทรัพยากรทั้งหมด : ทุกเลย์เอาต์ เมนู ไดอะล็อก ล็อก
  • แก้เส้นทางส่งออก : ไม่ใช่ตัวชี้นำ %1$s แต่เป็นพาธจริง
  • แก้เอาประกาศิกษาโฆษณาหลายภาษา : เติมอาร์กิวเมนต์ กำจัด MissingFormatArgumentException

ประวัติทั้งหมดใน CHANGELOG
