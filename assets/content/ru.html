📖 О проекте

Полный конвейер в один клик : распаковка → удаление рекламы → обход подписи → оптимизация размера → переупаковка → подпись, всё обрабатывается локально и офлайн, без сети.

Вместо традиционного smali-дизассемблирования/пересборки используется прямое исправление байт-кода, что в несколько раз ускоряет обработку с сохранением точности.

✨ Возможности

🛡 Обход подписи (новое в v3.0)

  • Инъекция KillerApplication в стиле MT Manager : инжектирует класс-хук с 12 внутренними классами как отдельный DEX, переписывает родительский класс Application и во время выполнения через рефлексию заполняет PackageInfo.CREATOR исходной подписью, покрывая большинство проверок Java
  • Двойной режим : Обычный (хуки для Java-слоя) / Исходный (усиленный, со встроенными origin.apk + нативной библиотекой для нативного слоя)
  • Умная инъекция SO : определяет ABI, пишет только в существующие каталоги (arm64-v8a / armeabi-v7a и т. д.) ; если нет lib — во все архитектуры (вкл. x86 / x86_64)
  • Имя класса-хука настраивается : KillerApplication свободно переименовывается, 12 внутренних классов переименовываются автоматически через dexlib2
  • Параметры инъекции настраиваются : путь оригинала / распаковки / имя so / класс-хук / подпись / точка входа ; пусто = реальные значения
  • Не трогает бизнес-методы : нет хрупких предположений, нет зависаний при запуске, та же надёжность, что у MT Manager
  • Защита от сбоев : резервная копия + атомарная запись + автовосстановление

🛡 Удаление рекламы

  • 18 категорий рекламных признаков : SDK-библиотеки / разрешения / классы / методы / ресурсы / URL / Views / Activities / Services / Receivers, настраиваемо со сбросом
  • Глубокая обработка AXML : удаляет рекламные компоненты, разрешения, скрывает рекламные Views
  • Точность на уровне методов : обнуляет методы, ссылки, геометрию
  • Разблокировка Premium : принудительный true/false для обхода рекламы
  • Очистка рекламных ресурсов : нативные SDK-библиотеки (.so), assets, корневые файлы
  • Поддержка Flutter : анализирует AOT-снимок Dart, стирает сигнатуры строк в libapp.so

📦 Оптимизация размера

  • Переиспользование данных : обойденные пакеты (например LSPatch) используют исходный сегмент, сокращая до ~50 %
  • Распознавание переименованных APK : без расширения или с любым расширением
  • Оптимизация DEX : удаление отладочной информации, ещё 5 %–15 %
  • Умное сжатие + выравнивание ZIP : гарантирует корректную установку

🔒 Стабильность и безопасность

  • Двойная подпись v1 + v2, совместимо со старыми устройствами
  • Защита от сбоев DEX : резервная копия + атомарная запись + восстановление
  • Защита path traversal : исправляет Zip Slip, блокирует запись за границы
  • Сканирование с низким потреблением памяти : большие DEX без зависаний

🎨 Опыт

  • 17 языков встроено (новое в v3.5) : 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Español / Français / Deutsch / Italiano / Português / Русский / हिन्दी / Tiếng Việt / ไทย / Bahasa Indonesia / العربية / Türkçe ; «по системе» или переключение в приложении, мгновенно

  • Авто-отчёт Markdown
  • Импорт и обмен рекламными подписками
  • Светлая/тёмная тема (система / свет / ночь)
  • Длинный текст переносится и отображается полностью, без многоточия (включая русский)

🚀 Быстрый старт

Сборка

# Требования : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Артефакты в app/build/outputs/apk/release/, устанавливаются напрямую.

У проекта есть GitHub Actions автосборка : каждый push/PR компилирует Debug & Release ; тег v* публикует Release с APK.

Описания версий через release-drafter : теги по заголовку/ветке/файлам и структурированный changelog.

Использование

  1. Выберите APK (включая переименованные)
  2. Нажмите «Начать» : распаковка, удаление, оптимизация, упаковка, подпись
  3. Экспорт в исходный каталог + отчёт Markdown

🆕 Что нового (v3.5)

  • Мультиязычный переключатель : 17 языков, «по системе» или в приложении, мгновенно
  • UI полностью вынесено в ресурсы : все макеты, меню, диалоги, журналы
  • Исправлен путь экспорта : вместо маркера %1$s — реальный путь
  • Исправлено мультиязычное удаление : дополнены аргументы, устранён MissingFormatArgumentException
