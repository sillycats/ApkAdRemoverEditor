📖 Tentang proyek

Alur lengkap sekali klik : ekstrak → hapus iklan → bypass tanda tangan → optimasi ukuran → kemas ulang → tandatangani, semuanya diproses lokal dan offline, tanpa jaringan.

Berbeda dari alur smali tradisional, alat ini menggunakan patch bytecode langsung, yang mempercepat pemrosesan beberapa kali lipat dengan tetap presisi.

✨ Fitur

🛡 Bypass tanda tangan (baru di v3.0)

  • Injeksi KillerApplication gaya MT Manager : menyuntikkan kelas hook dengan 12 kelas dalam sebagai DEX mandiri, menulis ulang kelas induk Application dan saat runtime mengisi PackageInfo.CREATOR dengan tanda tangan asli via refleksi, mencakup mayoritas cek Java
  • Mode ganda : Normal (hook untuk lapisan Java) / Original (diperkuat, dengan origin.apk + lib native untuk lapisan native)
  • Injeksi SO pintar : mendeteksi ABI, hanya menulis ke direktori yang ada (arm64-v8a / armeabi-v7a...) ; tanpa lib tulis semua arsitektur (termasuk x86 / x86_64)
  • Nama kelas hook dapat disesuaikan : KillerApplication bebas diganti nama, 12 kelas dalam otomatis berganti nama via dexlib2
  • Parameter injeksi sepenuhnya dapat disesuaikan : jalur asli / ekstrak / nama so / kelas hook / tanda tangan / entri ; kosong = baca nilai asli
  • Tidak menyentuh metode bisnis : tanpa asumsi rapuh, tanpa macet saat start, kekuatan sama seperti MT Manager
  • Perlindungan crash : cadangan + penulisan atomik + pemulihan otomatis

🛡 Inti penghapusan iklan

  • 18 kategori fitur iklan : lib SDK / izin / kelas / metode / sumber / URL / Views / Activities / Services / Receivers, dapat disesuaikan dengan reset
  • Pemrosesan AXML mendalam : menghapus komponen iklan, izin iklan, menyembunyikan View iklan
  • Presisi tingkat metode : mengosongkan metode kelas iklan, tautan, geometri View
  • Buka fitur premium : paksa true/false untuk melewati deteksi iklan
  • Pembersihan sumber daya iklan : lib native SDK iklan (.so), sumber assets iklan, file root iklan
  • Dukungan Flutter : menganalisis snapshot AOT Dart, menghapus tanda tangan string di libapp.so

📦 Optimasi ukuran

  • Reuse data : paket bypass (misal artefak LSPatch) menggunakan kembali segmen data asli, mengurangi hingga ~50 %
  • Deteksi APK yang diganti nama : tanpa ekstensi atau ekstensi apa pun
  • Optimasi DEX : hapus info debug, 5 %–15 % lebih kecil
  • Kompresi pintar + penyelarasan ZIP : memastikan instalasi normal

🔒 Stabilitas & keamanan

  • Tanda tangan ganda v1 + v2, kompatibel dengan perangkat lama
  • Perlindungan crash DEX : cadangan + penulisan atomik + pemulihan
  • Perlindungan path traversal : perbaiki Zip Slip, blokir penulisan di luar batas
  • Pemindaian berdaya rendah : DEX besar tetap stabil tanpa macet

🚀 Mulai cepat

Build

# Persyaratan : Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Artefak di app/build/outputs/apk/release/, siap diinstal.

Proyek ini punya GitHub Actions build otomatis : setiap push/PR mengompilasi Debug & Release ; tag v* mempublikasikan Release dengan APK.

Catatan rilis via release-drafter : otomatis menandai PR berdasarkan judul/cabang/file dan mengagregasi changelog terstruktur.

Penggunaan

  1. Pilih APK (mendukung APK yang diganti nama)
  2. Ketuk "Mulai" : ekstrak, hapus, optimasi, kemas, tanda tangan
  3. Ekspor ke direktori asli + laporan Markdown

🆕 Yang baru (v3.5)

  • Sakelar multibahasa : 17 bahasa, "ikuti sistem" atau di aplikasi, langsung
  • UI sepenuhnya di-resource : semua tata letak, menu, dialog, log
  • Perbaikan jalur ekspor : bukan marker %1$s, tapi jalur nyata
  • Perbaikan penghapusan multibahasa : melengkapi argumen, menghilangkan MissingFormatArgumentException

Riwayat lengkap di CHANGELOG.
