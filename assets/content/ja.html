📖 プロジェクト概要

解包 → 広告除去 → 署名回避 → サイズ最適化 → 再パッケージ → 署名 の全工程をワンクリックで実行。すべて端末内でオフライン処理し、ネットワークは不要です。

従来の smali 逆アセンブル・再アセンブル方式ではなく、バイトコードの直接パッチ方式を採用。処理精度を維持しつつ、処理速度を数倍に向上させます。

✨ 機能

🛡 署名回避（v3.0 で追加）

  • MT Manager 式 KillerApplication 注入：12 個の内部クラスを含むフッククラスを独立 DEX として注入し、対象アプリの Application 親クラスを書き換え、実行時に PackageInfo.CREATOR を反射で書き戻して元の署名を復元。Java 層の署名チェックの大半をカバー
  • 2 モードの署名回避：通常（フック注入で Java 層チェックをカバー）/ 原包（強化、origin.apk + ネイティブライブラリを追加で組み込み、APK 再読み込み時のネイティブ層チェックもカバー）
  • SO スマート注入：対象 APK の ABI を自動判別し、既存ディレクトリ（arm64-v8a / armeabi-v7a 等）のみに書き込み。lib ディレクトリがなければ全アーキテクチャ（x86 / x86_64 含む）に書き込み
  • フッククラス名をカスタマイズ可能：KillerApplication の名前を自由に変更でき、12 個の内部クラスは dexlib2 で自動的に同期リネームされ、特徴検出を回避
  • 注入パラメータを全面カスタマイズ：原包パス / 解凍パス / SO ライブラリ名 / フッククラス名 / 署名情報 / エントリ名。未入力時は実際の値を自動取得
  • 業務メソッドに触れない：「チェックメソッドを空にする」方式と異なり、脆弱なキーワード/フィンガープリント推測に依存せず、バイトコード空化による起動フリーズも発生せず、MT Manager と同等の強度
  • クラッシュ保護：フック DEX 注入と Application 親クラス書き換えはどちらもバックアップ + 原子書き戻し + 異常時自動復旧

🛡 広告除去コア

  • 18 カテゴリの広告特徴をカバー：SDK ライブラリ / パーミッション / クラス / メソッド / リソース / URL / View / Activity / Service / Receiver。カスタマイズとワンタッチリセットに対応
  • AXML 深度処理：広告コンポーネント、広告パーミッション宣言を削除し、Res レイアウトの広告 View を非表示
  • メソッドレベルで精密処理：広告クラスのメソッド空化、広告リンクの空化、View ジオメトリの空化
  • 会員機能のアンロック：true/false を強制返却し、会員機能を解除して広告判定を無効化
  • 広告リソースのクリーンアップ：広告 SDK のネイティブライブラリ (.so)、assets 広告リソース、ルート広告ファイルを自動削除
  • Flutter 対応：Dart AOT スナップショットを解析し、libapp.so 内の広告文字列特徴を消去

📦 サイズ最適化

  • データ再利用最適化：署名回避パッケージ（LSPatch 成果物など）が原包のデータセクションを再利用し、サイズを最大約 50% 削減
  • リネームされた APK も識別：拡張子なしや任意の拡張子にリネームされた原包も正確に識別して最適化
  • DEX サイズ最適化：デバッグ情報（行番号/ローカル変数テーブル）を削除し、さらに 5%〜15% 削減
  • スマート圧縮 + ZIP アライメント：再パッケージ後の APK が正常にインストール・起動できることを保証

🔒 安定性とセキュリティ

  • v1 + v2 二重署名、旧バージョンのデバイスとも互換、処理結果をそのままインストール可能
  • DEX クラッシュ保護：バックアップ保護 + 原子書き込み + 異常時自動復旧
  • パストラバーサル保護：Zip Slip を修正し、悪意のある APK による境界外書き込みを防止
  • 低メモリスキャン：巨大な DEX でも安定して処理、フリーズしない

🎨 使いやすさ

  • 17 言語の切り替えを内蔵（v3.4 で追加）：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Español / Français / Deutsch / Italiano / Português / Русский / हिन्दी / Tiếng Việt / ไทย / Bahasa Indonesia / العربية / Türkçe。「システムに従う」またはアプリ内でワンタップ切り替え、即時反映
  • リアルタイムのカラー処理ログ、ワンタップコピー / クリア
  • Markdown 処理レポートを自動生成
  • 広告特徴サブスクリプションのインポートと共有
  • ライト/ダーク双方向テーマ（システム連動 / ライト / ナイト）
  • 長文を自動で折り返して完全表示、省略記号で切らない（ロシア語などの長単語言語も対応）

🚀 クイックスタート

ビルド

# 要件：Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

成果物は app/build/outputs/apk/release/ にあり、そのままインストールできます。

本プロジェクトは GitHub Actions の自動ビルドを設定済み：push / PR のたびに Debug と Release を自動でコンパイル。v* タグを打つと Release を自動公開し APK 成果物を添付。

リリースノートは release-drafter が PR タイトル / ブランチ / 変更ファイルに応じて自動でタグ付け（feature / bug / docs / ci 等）し、公開時にカテゴリ別に構造化された更新ログとして自動集約。

使い方

  1. 処理する APK ファイルを選択（リネーム済み APK にも対応）
  2. 「処理開始」をタップすると、解包・広告除去・サイズ最適化・再パッケージ・署名を自動実行
  3. 処理完了後、元ディレクトリに自動エクスポートし、Markdown 処理レポートを生成

🆕 バージョン更新（v3.4）

  • 多言語切り替え：17 言語をサポート。「システムに従う」かアプリ内ワンタップ切り替えで即時反映
  • UI を完全にリソース化：全レイアウト、メニュー、ダイアログ、ログ文言を文字列リソースに統一し、各言語リソースを厳密に揃え、長文を自動折り返しで完全表示
  • エクスポートパス表示を修正：完了ログが %1$s プレースホルダーではなく実際のパスを表示
  • 多言語の広告除去を修正：文字列プレースホルダーの実引数を補完し、言語切り替え後に MissingFormatArgumentException で APK 処理が失敗する問題を解消

完全なバージョン履歴は CHANGELOG をご覧ください。
