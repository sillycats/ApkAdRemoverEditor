📖 Hakkında

Tek tıkla tam işlem hattı: aç → reklamları kaldır → imza atla → boyut optimizasyonu → tekrar paketle → imzala; tümü yerelde ve çevrimdışı işlenir, internet bağlantısı gerekmez.

Geleneksel smali sökme-yeniden birleştirme akışı yerine doğrudan bayt kodu yamalama (direct bytecode patching) kullanır; bu, hassasiyeti korurken işlem hızını birkaç kat artırır.

✨ Özellikler

🛡 İmza Atlama (v3.0'da yeni)

  • MT Manager tarzı KillerApplication enjeksiyonu: 12 iç sınıflı bir hook sınıfını bağımsız bir DEX olarak enjekte eder, hedef uygulamanın üst sınıfını (parent class) yeniden yazar ve çalışma zamanında yansıma (reflection) yoluyla PackageInfo.CREATOR alanını orijinal imzayla doldurur; çoğu Java katmanı imza kontrolünü kapsar
  • Çift modlu atlama: Normal (Java kontrollerini kapsamak için hook enjekte eder) / Orijinal mod (yerel katmandaki disk yeniden okuma imza kontrollerini kapsamak için ekstra origin.apk + yerel kütüphaneyi gömer)
  • Akıllı SO enjeksiyonu: hedef APK'nın ABI'sini otomatik algılar, yalnızca mevcut dizinlere yazar (arm64-v8a / armeabi-v7a vb.); lib dizini yoksa tüm mimarilere (x86 / x86_64 dahil) yazar
  • Özel hook sınıf adı: KillerApplication serbestçe yeniden adlandırılabilir, imza algılamayı önlemek için 12 iç sınıf dexlib2 ile otomatik yeniden adlandırılır
  • Tamamen özelleştirilebilir enjeksiyon parametreleri: orijinal yol / çıkarma yolu / so adı / hook sınıfı / imza bilgisi / giriş adı; boş bırakıldığında gerçek değerleri otomatik okur
  • İş yöntemlerine asla dokunmaz: "kontrol yöntemlerini boşaltma" yaklaşımının aksine kırılgan anahtar sözcük/parmak izi tahmini yoktur, bayt kodu boşaltmasının neden olduğu başlangıç donması yoktur, MT Manager ile aynı güçtedir
  • Çökme koruması (crash guard): hook DEX enjeksiyonu ve Application üst sınıfı yeniden yazma işlemleri, yedekleme + atomik geri yazma + otomatik kurtarma kullanır

🛡 Reklam Kaldırma Çekirdeği

  • 18 kategoride reklam özelliği: SDK kütüphaneleri / izinler / sınıflar / yöntemler / kaynaklar / URL'ler / Görünümler (Views) / Etkinlikler (Activities) / Hizmetler (Services) / Alıcılar (Receivers); sıfırlamayla birlikte tamamen özelleştirilebilir
  • Derin AXML işleme: reklam bileşenlerini ve reklam izin bildirimlerini kaldırır, Res-layout reklam Görünümlerini gizler
  • Yöntem düzeyinde hassasiyet: reklam sınıfı yöntemlerini boşaltır, reklam bağlantılarını ve View geometrilerini boşaltır
  • VIP açma: reklam yargılarını atlamak ve üyeliğin kilidini açmak için true/false döndürmeyi zorlar
  • Reklam kaynağı temizliği: reklam SDK yerel kütüphanelerini (.so), assets reklam kaynaklarını ve kök reklam dosyalarını otomatik temizler
  • Flutter desteği: Dart AOT snapshot'ını ayrıştırır, libapp.so içindeki reklam dizesi imzalarını siler

📦 Boyut Optimizasyonu

  • Veri yeniden kullanım optimizasyonu: bypass paketleri (örn. LSPatch yapıtları) orijinal veri bölümünü yeniden kullanır, boyutu %50'ye kadar küçültür
  • Yeniden adlandırılmış APK algılama: uzantısız veya rastgele uzantılı olarak yeniden adlandırılan orijinal paketleri doğru şekilde tanır
  • DEX boyut optimizasyonu: hata ayıklama bilgilerini (satır numaraları / yerel değişken tabloları) kaldırır, ek %5~15 daha küçük boyut elde eder
  • Akıllı sıkıştırma + ZIP hizalama: yeniden paketlenen APK'nın normal şekilde kurulup çalışmasını sağlar

🔒 Kararlılık ve Güvenlik

  • v1 + v2 çift imzalama, düşük sürümlü cihazlarla uyumludur, sonuçlar doğrudan kurulabilir
  • DEX çökme koruması: yedekleme koruması + atomik yazma + otomatik kurtarma
  • Yol geçişi koruması (path traversal): Zip Slip'i düzeltir, kötü amaçlı APK'nın sınırların dışına yazmasını engeller
  • Düşük bellek taraması: donmadan büyük DEX dosyalarını kararlı şekilde işler

🚀 Hızlı Başlangıç

Derleme

# Requirements: Android Studio / JDK 17+ / SDK 34
./gradlew assembleRelease

Çıktı app/build/outputs/apk/release/ konumundadır, doğrudan kurulabilir.

Bu projede GitHub Actions otomatik derleme vardır: her push/PR Debug ve Release derler; v* etiketi yayınlamak APK yapıtlarıyla birlikte Release'i otomatik yayınlar.

Sürüm notları release-drafter tarafından otomatik üretilir: PR'leri başlığa/dala/değiştirilen dosyalara göre otomatik etiketler (feature/bug/docs/ci vb.), sürümde yapılandırılmış değişiklik günlüğünü özetler.

Kullanım

  1. İşlenecek APK'yı seçin (yeniden adlandırılmış APK'lar desteklenir)
  2. "İşlemeyi Başlat"a dokunun: otomatik olarak aç, reklamları kaldır, boyutu optimize et, tekrar paketle, imzala
  3. Orijinal dizine otomatik dışa aktarılır, Markdown işleme raporu üretilir

🆕 Yeni Neler (v3.5)

  • Çok dilli anahtar: 17 dil, sistemi takip et veya uygulama içinde tek dokunuşla geçiş, anında etki
  • Tamamen dışa aktarılmış arayüz: tüm düzenler, menüler, iletişim kutuları, günlük kopyalama dize kaynakları olarak birleştirildi, diller sıkı bir şekilde uyumlu, uzun metin otomatik sarılır
  • Dışa aktarılan yol görüntüleme düzeltmesi: dışa aktarma günlüğü artık Exported: %1$s yer tutucusunu göstermez, gerçek yolu gösterir
  • Çok dilli reklam kaldırma düzeltmesi: dize yer tutucu argümanlarını tamamlar, dil değişikliğinden sonra APK işlemeyi bozan MissingFormatArgumentException hatasını ortadan kaldırır

Tam sürüm geçmişi CHANGELOG içindedir.
